# Innotrepid Security Android Bridge

This directory contains the native Android portion of the reusable Flutter security package.

## Play Integrity

The bridge uses Google's Play Integrity Android library and exposes a small MethodChannel to Dart:

- channel: `innotrepid_security/play_integrity`
- method: `requestToken`
- input: `requestHash`, `cloudProjectNumber`
- output: Play Integrity token

The application must provide the Google Cloud project number configured for its Play Integrity integration. No Google credential or private server key belongs in the APK.

The standard request hash is generated by the Flutter security client and must be sent unchanged to the backend. The backend verifies that the decoded token's request package, request hash and timestamp match the original request before trusting integrity verdicts.

See Google's current Play Integrity documentation for setup and verdict handling.
